Shy UI

A lightweight Windows tray app that hides the title bar of maximized windows — a cleaner fullscreen-style view that stays fully functional.

Windows · C# · WinForms

How it works

  • Auto-Shy — any window you maximize is managed automatically; the title bar slides off-screen.
  • Reveal on hover — move the mouse to the top 2px of the screen to peek the title bar.
  • Per-app control — add or remove specific apps from the managed list with a hotkey.
  • Pause & resume — restore every window to its normal state in one keypress.

Hotkeys

ActionKey
Pause / Resume allCtrl+Alt+S
Add / remove focused appCtrl+Alt+T
Reveal hidden title barMouse to top 2px of screen

Build

No SDK required — uses the .NET Framework compiler bundled with Windows:

powershell -ExecutionPolicy Bypass -File build.ps1
